## Validation evidence

- GitHub Actions passed Claude Code strict validation and unit jobs on
  Ubuntu/Python 3.9, macOS/Python 3.13, and Windows/Python 3.13. The Windows
  polyglot Hook launcher probe passed.
- Before publication, 202/202 aggregate unit tests and 11/11 skill validators
  passed locally.
- Codex plugin validation, Claude Code strict validation, Qoder plugin
  validation, OpenCode syntax validation, Python compilation, JSON validation,
  manifest checks, and `git diff --check` passed locally.
- The release adds the default-off Delegation Gate without a new top-level
  skill, root `agents/` directory, ledger schema field, background scan, or
  model call on the default single-agent path.
- Delegation still requires a stable task, a material expected benefit, and
  explicit user authorization. The root remains responsible for ledger state,
  integration, verification, and completion.

## Evaluation boundary

This alpha does not claim authenticated three-run delegated performance
certification across GPT-5.6, Claude Opus 4.8, and Qoder. It establishes the
portable protocol, deterministic package checks, conservative host adapters,
and a default-off safety boundary. Current-host installation is verified
separately after the release ledger closes.
