# Littlepowers v0.4 engineering discipline implementation plan

**Date:** 2026-07-17

**Status:** Execution in progress

## Goal

Ship systematic debugging, evidence-gated verification, and lightweight change review as three independently reversible native skills for Codex and Claude Code, with proportional test scope and no new recovery-state or hook behavior.

## Inputs

- Brainstorm: `docs/littlepowers/brainstorms/2026-07-17-v0.4-engineering-discipline.md`
- Specification: `docs/littlepowers/specs/2026-07-17-v0.4-engineering-discipline.md`
- Design: `docs/littlepowers/designs/2026-07-17-v0.4-engineering-discipline.md`
- Existing integration points: `skills/executing-plans/SKILL.md`, `skills/writing-plans/SKILL.md`, plugin manifests, documentation, eval scenarios, and manifest tests

## Global constraints

- Keep one shared skill implementation for Codex and Claude Code.
- Do not change hooks, state schema, state CLI, model selection, reasoning effort, or repository visibility.
- Do not require hidden reasoning disclosure, mandatory TDD, subagents, worktrees, or full-suite testing for local changes.
- Preserve diagnosis-only authority: inspection does not imply permission to edit.
- The coordinator is the only ledger writer; worker evidence must be rechecked after integration.
- Use `apply_patch` for hand edits and the standard skill initializer only for initial scaffolding.
- Keep feature changes in independent commits so one capability can be reverted without reverting the others.

## Validation and rollback policy

| Boundary | Rollback unit | During implementation | Aggregate release check |
| --- | --- | --- | --- |
| Debugging | Skill, focused test/eval, one commit | Skill validator + named debugging contract tests | Included once in full suite |
| Verification | Skill, execution/plan integration, focused test/eval, one commit | Skill validators + named verification/integration tests | Included once in full suite |
| Review | Skill, focused test/eval, one commit | Skill validator + named review contract tests | Included once in full suite |
| Packaging/release | Docs, manifests, release metadata, one commit | Manifest/document tests + both plugin validators | Full suite, all skills, install smoke, platform CI |

No full test suite runs between small edits. A failed focused check is repaired and rerun at its own boundary. The complete suite runs after the combined plugin surface is ready because skill discovery, package metadata, and both hosts are then affected.
