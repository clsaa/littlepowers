# Littlepowers 1.5.1 — Acceptance repair and evidence continuity

This patch is integrated on top of v1.5.0, retaining its verification-input
freshness, exact plan-approval checks, recovery protections and execution-
efficiency helper. No ledger/protocol migration or runtime dependency is added.

## Fixes

- Failed or blocked fidelity comparisons no longer make a lawful repair plan
  impossible to review. Missing/drifted approved sources, incomplete coverage,
  scope changes and required approvals still block as before.
- Returning to execution invalidates old completion verdicts. Plan validation
  and contract rebind preserve the previous evidence artifact for recovery,
  while current verification becomes pending. Attempt files remain distinct;
  a historical report is not current completion authority.

## Acceptance and efficiency

One on-demand reference now requires acceptance from the original user's entry
point through persisted final results, including relevant historical data.
Applicable terminals, actual tools and explicitly approved exemptions are scoped
before testing; valid unchanged browser grants are reused without bypassing
revocation or host prompts. Evidence reuse requires dependency/environment
continuity, with affected checks rerun after changes.

The instructions reuse existing verification-input and execution-efficiency
helpers. Saved raw output, bounded summaries and operation receipts prevent
unnecessary output replay or blind business-write resubmission. No automatic
subagent, background scan, new orchestrator, global configuration edit or model
setting change is introduced. Text-volume measurements are not model-speed,
cost or compression claims.

## Validation boundary

Release validation covers 309 passing integrated local tests, all 11 official
skill validators, Claude/Qoder plugin validation, and Codex installation/file-
integrity checks. The user explicitly authorized local validation without new
cross-platform CI for this release; the manually disabled test workflow remains
disabled. No new CI result or cross-platform certification is claimed.
The user also explicitly authorized official
Codex CLI isolated installation, manifest parsing and byte comparison as the
