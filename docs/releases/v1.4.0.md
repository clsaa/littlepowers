# Littlepowers v1.4.0

Littlepowers 1.4.0 adds opt-in native delegation with a benefit check, explicit
work-unit authorization, host capability validation, and single-agent fallback.
Small tasks retain the direct route, and the coordinator owns integration,
workflow state, and final acceptance.

The release updates Codex, Claude Code, and Qoder context/model/permission
guidance, corrects Qoder Hook support, and adds behavioral capability tests.
Real Codex tests also exposed and repaired false leaf-enforcement labeling:
worker instructions cannot stand in for a disabled delegation tool or an
effective host depth limit.

Authenticated Sol/max tests exercised tiny changes, planning approval, a
status question while waiting, process interruption, and same-session recovery
through complete PRD implementation. Local verification includes 208 passing
unit tests, all 11 skills, the Codex plugin validator, Claude Code 2.1.278
strict validation, and Qoder CLI 1.1.58 validation.

Native delegation depends on the actual host controls. The tested default
Codex worker interface could not prove leaf enforcement, so the repaired
candidate correctly falls back to single-agent execution. Fresh/fork/team
adapters are capability-conditional; this release makes no blanket multi-agent
speedup, model reliability, or cross-host orchestration-certification claim.

Protocol 1.3 and schema 4 are unchanged. Existing workflows retain their state.
Load updated skills at a new session/task boundary after installation.

See [the authenticated test report](../../evals/results/2026-09-20-v1.4.0-codex-live.md)
for timings, the failed pre-repair run, the fix, and evidence limits.

## Release verification

Publication requires Linux, macOS, Windows, and Claude Code CI on the exact
release commit, aligned package/marketplace versions, source/tag identity,
and isolated exact-tag installation checks. The GitHub release records the
source commit and CI run. Installation examples use the stable `v1.4.0` tag.
