# Littlepowers 1.4.3 — Eval privacy and recovery replay

Live-eval reports now default to minimal typed metadata. Command output, tool
payloads, agent messages and raw errors stay out of the shareable report.
Explicit `--sensitive-log` creates a separate unredacted diagnostic file;
inspect it before sharing. Report version 2 is intentionally smaller: consumers
must not expect raw event bodies. The host's own history is unchanged.

OpenCode recovery no longer retries empty hooks because assistant/tool messages
accumulate. Successful context is reapplied to reconstructed native message IDs
without rerunning the hook. Concurrent transforms share pending attempts;
bounded caches are isolated by plugin instance and session, with deletion cleanup.
Observed child sessions receive the shared worker marker, which is advisory
metadata and does not enforce host permissions. Missing lifecycle events,
restart/eviction and anonymous reconstructed messages remain limited.

Offline regressions exercise synthetic canaries and host fixtures. No paid live
evaluations or installed-host certification are claimed. Local candidate validation is recorded in
[the implementation evidence](../littlepowers/evidence/2026-10-01-eval-recovery.md).
Publication requires successful Linux/macOS/Windows and Claude CI on the release
commit. The standalone official Codex plugin validator was unavailable in the
release executor and is not claimed as passing. Live installed-host behavior
remains unverified.
Protocol 1.3 and schema 4 remain unchanged. Install/update at a new session
boundary; do not hot-load this development tree into the stable workflow runtime.
