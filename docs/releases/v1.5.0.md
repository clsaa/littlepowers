# Littlepowers 1.5.0 — Execution efficiency

Validation and release exceptions were explicitly approved by the user:
independent-context, read-only-convention review with before/after hashes (not
forced isolation); disable repository Actions before push and release using local
validation without new cross-platform CI; and waive the unavailable official Codex
plugin validator for this release. These are declared exceptions, not passing
checks. All EFF-01 through EFF-12 remain in scope. Host certification is limited
to the evidence below; unsupported capabilities retain explicit degradation.

Large results can now be preserved as evidence before emitting structured check
coverage, critical findings and visual references. The standard-library helper
compares stable semantic entity fields, detects same-name control swaps and
versions, distinguishes unknown/error/empty states, and proposes recoverable
pending-event cursors. Saving does not acknowledge delivery; uncertain receipts
may redeliver read-only events but never replay business operations.

Host adapters retain tool calls, existing handles, actual time limits,
cancellation and periodic reporting. Missing capabilities degrade explicitly.
The helper makes no tool/network/browser/agent calls, launches no monitor, adds
no telemetry and does not write the existing ledger or bypass its gates.

Local tests cover the protocol and a cooperative asyncio host fixture. A separate
identity-bound Linux process SIGTERM probe verified receipt, stopped heartbeat
and process disappearance. Console Ctrl-C did not deliver the expected signal;
that failure is preserved. Neither result certifies browsers, arbitrary tools,
other hosts, or macOS/Windows.

Three paired synthetic runs (40 observations and 80 checks per arm) emitted
807,710 characters in the full-output arm versus 3,759 in the summary arm.
Local wall time increased; tool calls remained 40. No host model request counts,
context-token measurements or compression benefits are claimed. See the
[full evidence and limitations](../littlepowers/evidence/2026-10-17-execution-efficiency.md)
and [raw experiment](../littlepowers/evidence/2026-10-17-efficiency-benchmark.json).

This is an additive feature and a new optional efficiency schema v1. Littlepowers
protocol 1.3 and ledger schema 4 remain unchanged; no old-user-data migration or
new compatibility layer was introduced. Install the eventual v1.5.0 tag at a new
session boundary, after publication; do not hot-load into an active workflow.

Release procedure: freshly verify the exact candidate, confirm all relevant
repository Actions workflows disabled before any push, fast-forward main, and
publish an immutable v1.5.0 tag/Release. No new CI result is claimed. See the
[release verification](../littlepowers/evidence/2026-10-17-v1.5.0-release.md) for
candidate review, local checks and subsequent remote-publication evidence.
