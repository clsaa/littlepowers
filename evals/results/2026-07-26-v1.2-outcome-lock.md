latency guarantee. Ordinary prompt/Hook paths do not perform these parses or

The first aggregate invocation exposed two issues before the passing rerun:

1. Python tests inherited the broken `/usr/local/bin/node`, whose Homebrew
   binary referenced a missing `libsimdjson` library. The original OpenCode
   reproducers passed with the supported NVM Node 24.15.0, and the final matrix
   exported that PATH before starting Python.
2. An old regression expected a tracked-direct objective to change through an
   execution checkpoint. Protocol 1.2 makes that objective the Contract, so the
   supported behavior is an atomic rejection with explicit replace/reconcile
   guidance. The focused reproducer and final suite passed after aligning the
   behavior, test, reference, and router.

and used only the public source CLI:

   `reconcile_required` while the current file remained schema 2.
2. An execution-progress checkpoint failed and created no archive.
3. A reconciliation-only checkpoint created one exact logical
   `pre-schema3-v2` archive before the first schema-3 write.
4. `bind-contract` bound the approved bootstrap Contract and its seven explicit
   sources.
5. `validate-plan` reported 23/23 active Outcomes mapped.
6. A changed requirements source became `drifted` and blocked transition to
   verification without adopting a new digest.
7. Restoring the approved bytes and explicitly rechecking returned the original
   bound state.
8. Completion without a Verification Record reported all current verdict and
   record failures without advancing the revision.
9. `record-verification` stored 23 passing Outcomes, four passing Fidelity
   comparisons, three independent verdicts, and zero blockers.
10. `complete` succeeded from `phase=verify`; exactly one migration archive
    remained.

The temporary fixture was destroyed by the test. The repository's live
schema-2 ledger was not run through the edited source CLI.

## Limits and release boundary

- No authenticated GPT-5.6 Sol xhigh/max/Ultra, Fable 5, or Opus 4.8 behavior
  run was performed. No reliability claim is made for those models.
- Windows was not executed locally. Existing launcher, path, and state tests
  remain CI-compatible, but this report does not claim a fresh Windows host
  run.
- Outcome Lock deterministically checks the reviewed ID contract, explicit
  file digests, declared mappings, evidence presence/digests, verdict
  consistency, and lifecycle transitions. It cannot detect a free-form
  requirement omitted from the first reviewed Contract or authenticate an
  approval/evidence claim.
- The aggregate verification was completed before commit, tag, publication,
  or installation. Those separately authorized release actions must preserve
  the verified tree and be checked independently after publication.
- An already-open task cannot hot-load 1.2. Installation and a new
  task/session boundary are required before a live schema-2 workflow can
  reconcile under the new runtime.
