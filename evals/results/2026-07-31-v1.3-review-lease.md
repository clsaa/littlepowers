  live Codex callback creation was not certified. The durable gate and
  conditional adapter contract were tested instead.
- The local `codex` CLI wrapper points to a missing packaged binary, so the
  official bundled plugin validator was used; no CLI install/discovery run is
  claimed.
- No authenticated GPT-5.6 Sol xhigh/max/Ultra, Fable 5, Opus 4.8, or Opus 5
  implementation/interruption flow was run. Fake-host evidence is not model
  quality evidence.
- Windows was not executed locally. Existing path, launcher, state, and
  fail-closed branches remain covered where this platform can exercise them.
- Review Lease cannot authenticate a coordinator's approval or
  no-intervention audit claim, infer a free-form requirement omitted from the
  reviewed Contract, or prevent a same-account process from stopping a sleeper.
- Commit, push, tag, GitHub release, marketplace publication, and local plugin
  installation were outside this implementation authorization and have not
  occurred.
