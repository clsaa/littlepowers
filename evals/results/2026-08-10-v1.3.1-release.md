# Littlepowers 1.3.1 release-candidate verification

**Date:** 2026-08-10

**Candidate:** `1.3.1`

**Protocol/schema:** Outcome Lock and Review Lease protocol 1.3, schema 4

## Why this patch exists

A review of recent Codex tasks found two repeatable continuity costs that the
plugin can address without adding ceremony:

1. Tasks are often launched from a parent workspace directory. When that
   non-Git parent had an unfinished ledger, the 1.3.0 Hook injected the parent's
   unrelated objective before the named child repository could establish its
   own context.
2. One workflow bound a test file that the approved implementation would later
   edit as an immutable Contract source. The drift gate failed safely, but the
   source-authority mistake created avoidable reconciliation work.

The audit also found that a current Codex runtime ignored two starter prompts
because they exceeded 128 characters. Long Full-route work still showed normal
context compaction and several explicit approvals, but the sampled work had
material unresolved product decisions; that is not evidence for another phase,
schema, autonomous reviewer, or blanket artifact limit.

## Candidate behavior

- Automatic Hook recovery now injects only when the discovered ledger root is
  itself a Git repository or worktree root. A non-Git manager ledger remains
  available to explicit state CLI and Project Workflow Index commands.
- The guard adds one `.git` marker `lstat` and no new Git process, child/sibling
  scan, prompt/transcript read, mutation, network access, background loop, or
  model call.
- All Codex starter prompts are at most 128 characters.
- Router, execution, and Outcome Lock guidance require stable acceptance inputs
  as Contract sources. Planned write targets and generated implementation
  evidence stay outside `sources`; reviewed Outcomes carry a source-free latest
  request.
- Version metadata is aligned at `1.3.1`; protocol 1.3 and schema 4 are
  unchanged.

- Codex plugin validation, Claude strict validation, Qoder plugin validation,
  Python compile, OpenCode JavaScript syntax, and `git diff --check` passed.
- Direct source reproduction from `/Users/nathan/workspace` emitted no Hook
  context, while the Littlepowers Git root emitted the exact active workflow.

The first raw Codex plugin-validator invocation lacked the optional PyYAML
dependency. Re-running the same validator in its declared `uv --with pyyaml`
environment passed; this was a validator-launch dependency issue, not a
candidate failure.

exact commit that passes Linux, macOS, Windows, and Claude Code CI. Exact-tag
clone/package smoke and local three-host replacement happen only after that
