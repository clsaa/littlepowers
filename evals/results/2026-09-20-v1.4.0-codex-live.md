# Littlepowers 1.4.0 local Codex acceptance report

Date: 2026-09-20. Candidate metadata: `1.4.0`; not yet published.

## Test boundary

These were authenticated local Codex executions through the existing ChatGPT
login. The installed CLI was 0.147.0; 0.155.1 was also executed locally from
its isolated npm package. The parent model was `gpt-5.6-sol` at `max`, matching
the inspected local configuration. Each fixture used a disposable Git repo.

The candidate was loaded by its explicit source skill path with
`--ignore-user-config` and a native workspace-write or read-only sandbox.
This tests candidate skill/state behavior, not production plugin-cache
replacement or live Hook installation. Package validators and deterministic
Hook tests cover the structural surfaces. No authenticated Astra, Claude,
Qoder, or OpenCode implementation run is claimed here.

`evals/run_codex_live.py` is an opt-in evaluator, never called by plugin
runtime. It retains observable command, file-change, worker, message, and usage
events in the disposable parent directory; reasoning events are excluded.
Codex retains its own normal session history for native resume.

## Defect found and repaired

The helper accepted `nested_delegation=blocked` without requiring an effective
native leaf boundary. The coordinator passed that value but later reported
that leaf behavior was imposed only by worker instructions. Read-only
filesystem enforcement worked; nested-delegation enforcement was unproven.

The helper now requires `leaf_boundary=tool-disabled|host-depth-limit`, rejects
`prompt-only`/`unknown`, and reports all violated boundaries together. The
reference rejects role names, worker prompts, or unverified configuration keys
as proof and prohibits relabeling failed observations without new native
evidence. Contradictory mutation/read-only claims also fail; regressions cover
these cases. The evaluator removed an unverified `agents.max_depth=1` setting
instead of treating its presence as enforcement.

This remains a coordinator-observation validator, not an interposer on Codex
tools. It cannot authenticate false claims or prevent skipping the helper.
