# Code of conduct

Littlepowers welcomes contributors with different backgrounds, experience levels, identities, and viewpoints.

## Expected behavior

- Discuss ideas and code with respect and technical specificity.
- Critique the work, not the person.
- State uncertainty and correct mistakes openly.
- Respect privacy, security disclosures, and contributor boundaries.
- Make space for questions and explain project-specific context.
- Accept maintainer decisions while remaining free to disagree constructively.

## Unacceptable behavior

- Harassment, threats, discrimination, or sexualized attention.
- Personal attacks, insults, trolling, or sustained disruption.
- Publishing private information without permission.
- Pressuring someone to disclose credentials, private code, identity, or personal contact details.
- Using project channels to promote unrelated products or campaigns.

## Enforcement

Report conduct concerns privately to the repository owner through their GitHub profile. Include links or screenshots when safe. The maintainer may edit or remove content, close discussions, restrict participation, or ban accounts according to severity and pattern.

The maintainer will protect reporter privacy as far as practical and will not retaliate against good-faith reports.

This policy applies in repository discussions, issues, pull requests, reviews, and project-related private communication.
